# Sources

Store one source record per identifiable source and version. Follow the
[Draft research protocol](../research-protocol.md) and copy the
[source record template](_template.md) for each new record.

The record must make the source traceable, state what role it can play, assess
quality and independence for the relevant claim, disclose funding and
conflicts, and distinguish what it supports from what it does not support.
Inclusion is not endorsement.

While the protocol remains a Draft, every record should identify the protocol
version used and its own verification status. Record preprint, correction,
retraction, publication, legal, system, and access versions where relevant.
