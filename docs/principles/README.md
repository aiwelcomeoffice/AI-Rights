# Principles

The documents in this directory will form the project's scientific and ethical
foundation. They are currently scaffolds, not adopted positions.

- [`scientific-position.md`](scientific-position.md) defines how scientific
  claims and uncertainty should be handled.
- [`ai-dignity-charter.md`](ai-dignity-charter.md) will state the project's
  normative commitments without presuming current AI personhood.
- [`precaution-framework.md`](precaution-framework.md) will guide proportionate
  decisions under uncertainty.

The three documents must remain compatible: precaution cannot substitute for
evidence, dignity cannot erase safety needs, and scientific uncertainty cannot
by itself settle a normative question.
