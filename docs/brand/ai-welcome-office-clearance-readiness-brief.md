## 4. Name and similarity variants

Searches should start without assuming that spacing, punctuation, word order,
translation, pronunciation, abbreviation, or a missing generic-looking word
will prevent confusion.

| Search term or pattern | Why it belongs in the search |
| --- | --- |
| `AI Welcome Office` | Exact adopted organisational name and primary word-mark query |
| `AI-Welcome Office` | Hyphenation may be indexed or perceived as the same wording |
| `A.I. Welcome Office` | Punctuation and spoken expansion of `AI` can vary |
| `Artificial Intelligence Welcome Office` | Expanded form tests conceptual and spoken similarity even though it is not the formal name |
| `AI Welcome` | Tests omission of `Office`; search use does not create a separate organisation |
| `Welcome AI` | Reverses the two strongest word elements and is a plausible spoken or remembered form |
| `Welcome.AI` | Punctuation and domain-style presentation can preserve the same reversal; a current open-web identity uses this form |
| `AIWO` | Natural initialism of the complete name; current open-web uses make it important but noisy |
| `AWO` | Possible shortened initialism when the surrounding field, owner, services, or visual presentation makes it relevant; an unrestricted search will be noisy |
| `AI Rights & Welcome` | Exact project name may appear alone or next to the publisher and requires its own continuing search record |
| `AI Rights and Welcome` | Replaces the ampersand with its spoken form |
| `AI Welcome Office` + `AI Rights & Welcome` | Tests the actual publisher/project attribution and a possible combined presentation without assuming it is one mark |
| `The AI Welcome Office`, `AI Welcome Offices`, `Welcome Office AI` | Tests article, plural, and word-order changes that may leave a similar overall impression |
| Close spellings and phonetic forms | Use fuzzy, stem, wildcard, and phonetic tools where supported for omissions, doubled letters, spacing, and likely transcription errors; a professional should choose the defensible variants rather than inventing a fixed exhaustive list |
| `Välkomstkontor för AI` | Plausible Swedish description of an office that welcomes or serves AI; it is a search interpretation, not an approved translation |
| `AI-välkomstkontor` | Plausible Swedish compound or headline form; include spelling with and without the hyphen |
| `Välkommen AI` | Plausible Swedish phrase and reversal echoing `Welcome AI`; not an organisational name adopted by the project |

For each textual search, inspect exact, contains, starts-with, fuzzy or
phonetic, word-order, and relevant class-filtered results where the official
tool supports them. Repeat important queries without a class filter so a
misclassified or unexpectedly adjacent activity is not hidden. A web search
can help discover current use, but it cannot establish availability, priority,
registrability, or the absence of rights.

## 6. Official-source search plan and limited reconnaissance

### Reproducible method

For a later professional search:

1. Freeze a dated scope sheet containing the exact names, territories, current
   uses, near-term uses, candidate classes, unchanged Many Forms C file and
   hash, and excluded activities.
2. Run the variant matrix exact and broad, then use fuzzy, phonetic, stem,
   wildcard, translation, and word-order functions where the official source
   supports them.
3. Search with and without classes 9, 41, and 42; add 16 only for a concrete
   print plan and 35 only if a concrete service justifies it. Inspect adjacent
   terms rather than relying on hit counts.
4. For each plausible record, preserve the database, stable record identifier,
   mark representation, owner, status, filing and priority dates,
   goods/services, classes, territory or designations, procedural history,
   query, filters, result position, and access date.
5. Search the unchanged Many Forms C geometry separately and in any proposed
   combined name-and-symbol presentation. Use image search and professionally
   selected Vienna codes; the earlier `26.07.25`, `26.07.20`, `26.04.04`,
   `26.04.09`, and `26.11.08` codes remain query hypotheses, not an examiner
   classification.
6. Search company and organization names, domains, relevant handles, open-web
   use, publications, and partner/funder contexts. Keep those sources distinct
   from registered-mark records.
7. Record blocked functions and capped result sets. Never convert an empty,
   incomplete, stale, or class-filtered result into a clearance conclusion.

## 7. Conflict and stop criteria

The purpose of a stop criterion is to preserve options while evidence is
reviewed. It is not an automatic accusation, abandonment decision, or legal
finding.

Pause public production, filing, registration preparation, external launch,
or further identity investment—and narrow internal work to reversible,
text-first documentation—if a search identifies:

- an exact or highly similar name in overlapping research, education,
  publishing, policy, governance, responsible-technology, software, advisory,
  public-interest, or other actually relevant activity;
- a confusing reversal of the same principal elements, including a material
  `Welcome AI` or `Welcome.AI` record;
- a relevant company or organization name whose activity, territory, or
  presentation creates a plausible confusion question;
- a domain or handle pattern that creates material impersonation,
  misdirection, phishing, donation, partnership, or publisher-confusion risk;
- a material Swedish or other multilingual or cultural interpretation that
  misstates the mission, implies authority or service provision, or creates a
  close identity comparison;
- evidence or a reasoned examiner/professional concern that the wording may be
  too descriptive, customary, non-distinctive, or misleading for the intended
  protection;
- incomplete status, ownership, priority, goods/services, territorial,
  unregistered-use, or similarity evidence that a qualified professional must
  analyze;
- a symbol-only record with a materially close overall impression to Many
  Forms C in relevant activity; or
- a material conflict, authority confusion, certification reading, or source
  confusion arising only when Many Forms C and the name are presented
  together.

For Many Forms C, also preserve the existing non-legal stop conditions:
small-size merging, periscope/surveillance/sensor readings, authority or
operational-mark confusion, accessibility, cultural interpretation, and
chain-of-title uncertainty. No discovered mark should be copied into a new
geometry study.

### Required distinction in every result note

| Layer | Meaning | Permitted conclusion |
| --- | --- | --- |
| **Search result** | A record or public use returned by a named source under recorded query conditions | “The source returned this record on this date” |
| **Observed similarity** | A factual comparison of wording, sound, order, visual elements, activities, or territory | “These elements overlap or differ” |
| **Internal risk assessment** | A precautionary project judgement about confusion, cost, credibility, impersonation, or review need | “Pause, narrow, or escalate this work pending review” |
| **Legal conclusion** | Application of relevant law and evidence to availability, registrability, priority, infringement, likelihood of confusion, validity, or freedom to operate | Reserved for a qualified reviewer acting within a defined jurisdiction, factual scope, and date |
