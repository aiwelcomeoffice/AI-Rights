# Decision Records

This directory preserves important scientific, ethical, product, governance,
and technical decisions with their context and consequences.

Use [`template.md`](template.md) and the filename pattern
`NNNN-short-description.md`. Decision numbers are sequential. Accepted records
are not silently rewritten; add a new record that supersedes the old one.

Committing a proposal does not mean it has been accepted. Each record must name
its status and decision date.
